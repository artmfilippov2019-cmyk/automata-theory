# Теория автоматов

## Recognizer

Распознаёт строки вида `nfs://server/path/to/file` и собирает статистику по именам серверов. Распознаватель реализован в трёх вариантах с общим интерфейсом `IRecognizer`: на Boost.Regex, на сгенерированном Flex-лексере и на конечном автомате, описанном для SMC (State Machine Compiler). Помимо основной программы есть генератор тестовых данных (`Generator`) и утилита для сравнения скорости трёх реализаций (`TimeCounter`).

Зависимости: Boost.Regex, Flex, Java и SMC (`Smc.jar` и `statemap.h`; путь к jar можно передать через `-DSMC_JAR=...`).

## Regular expression library

Библиотека регулярных выражений, построенная с нуля: разбор выражения в AST, построение НКА, переход к ДКА и его минимизация. Поддерживаются захватывающие группы, проверка соответствия строки, дополнение и пересечение языков, проверка эквивалентности двух выражений и восстановление регулярного выражения по автомату. Автоматы и AST можно выгрузить в Graphviz (`.dot`).

Зависимости: CMake ≥ 3.22, компилятор с C++20. Catch2 для тестов скачивается автоматически; Graphviz опционален (для картинок).

## Interpreter

Интерпретатор собственного языка для робота, который ищет выход из лабиринта. Язык поддерживает типы `LOGIC`, `NUMERIC`, `STRING`, массивы, процедуры (`PROC`), условия и циклы, а робот управляется командами `MOVE*`, `PING*` (датчик расстояния), `VISION` и `VOICE` (ввод пароля на выходе). Лексер написан на Flex, парсер на Bison, выполнение пошагово визуализируется в консоли.

Зависимости: Flex, Bison.
Лабиринты лежат в `mazes/`, программы для робота — в `programs/`.
